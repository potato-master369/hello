BUILD
====================================================

Please run the following commands in a Bourne Shell.
These are only guaranteed to work on the supported environments (Excluding Windows NT)

./configure

The above command configures the project for your selected environment

make

The above command builds the project.

sudo make install

The above command installs the project.
